# Travel Booking System(Mini Project)

## Problem Statement
Design a **Travel Agency System** where customers can make bookings for trips. 

The system should maintain customer records and booking details.

## Overview
The **Travel Booking System** is a Python-based application designed to manage travel bookings for customers.  
It demonstrates **Object-Oriented Programming (OOP)** concepts, including class design, exception handling, and modular coding.

# Project Structure

travel_booking_system/

│── main.py         # Entry point (menu-driven system)

│── customer.py     # Customer class

│── booking.py      # Booking class

│── travel_agency.py# Main system (manages customers + bookings)

│── report.py       # Report generation

│── exceptions.py   # Custom exceptions

│── utils.py        # Helper utilities (ID generator, validation)

│── README.md       # Instructions for students



## Topics Covered
- OOP (Customer, Booking, TravelAgency)
- Lists & Dictionaries
- Exception Handling
- Reports & Summaries
- Modular Programming

1. Create Customer class
2. Create Booking class
3. Implement TravelAgency class
4. Add exception handling
5. Build menu in main.py
